## Synthèse exécutive

**Le blocker n°1 reste le packaging** : les checklists disent « Desktop Beta v1.0.0 prête » mais l'app packagée ne peut ni générer un mesh (trellis2_native exige torch 2.8 + kaolin, jamais installés par `wizard_install_deps.py` qui pose torch 2.7.0 sans kaolin), ni auto-rigger (venv Puppeteer jamais provisionné chez l'utilisateur), et le CI de release sort un installeur sans python-embed ni vc_redist (gitignorés, jamais fetchés par le workflow). Cela confirme et précise le statut MSIX déjà connu.

**5 features visibles mais cassées pour l'utilisateur** :
1. Animation « Custom (text prompt) » desktop — le prompt n'est jamais lu, échec systématique.
2. Notation marketplace cloud — mismatch `{stars}` vs `{rating}`, 400 à chaque tentative.
3. Contrôle parental cloud — le scan NSFW visuel est un stub « toujours safe » ; aggravé côté desktop par un NameError qui neutralise le tampon NSFW dans `local_juggernaut_bridge.py`.
4. Paint Emissive desktop — modal complet mais bouton d'entrée absent du HTML.
5. Retarget FBX cloud — panneau UI présent, zéro handler.

**2 risques de perte réelle** : le swap post-process non atomique d'`image-to-3d` peut détruire le mesh fraîchement généré puis geler le job à jamais (main.js:5996) ; le remboursement de crédits cloud avalé par `.catch(() => {})` avec suppression du job record = perte monétaire silencieuse (worker.ts:7693).

**La parité desktop↔cloud a fortement dérivé** sur les développements récents : Recolor/Age/outils texture IA n'existent que sur desktop ; Paint Mesh, animations multi-types et Import GLB n'existent que sur cloud.

**Bonne nouvelle** : quasi tous les findings HIGH de l'AUDIT_2026-05-29 (Stripe, contrats renderer↔worker, SSRF) sont réellement corrigés ; aucun secret commité (les tokens trouvés sur disque sont bien gitignorés) ; le câblage IPC invoke est sain ; les gros scripts Python n'ont ni stub ni NotImplementedError.

### 7. [HAUTE] Génération 3D : swap post-process non atomique peut détruire le mesh généré puis geler le job à jamais
