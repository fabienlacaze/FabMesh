===============================================================
 1. DESCRIPTION   (champ « Description », obligatoire)
===============================================================

MyFabmesh.AI transforme une simple description ou une image en modele 3D
texture, prêt pour votre moteur de jeu.

Decrivez ce que vous voulez — « un casque de chevalier grave » — ou
partez d'une image que vous avez deja. L'application genere l'image de
reference, la convertit en maillage 3D texture, puis peut lui poser un
squelette et l'animer. Export en GLB, FBX et OBJ, utilisable directement
dans Unreal Engine, Unity ou Blender.

DEUX FACONS DE L'UTILISER

· Avec une carte NVIDIA : tout tourne sur votre machine. Aucune limite,
  aucun abonnement, vos creations ne quittent pas votre ordinateur. Les
  modeles d'IA (environ 15 a 22 Go selon le mode d'installation) se
  telechargent au premier lancement.

· Sans carte NVIDIA : l'application bascule automatiquement sur notre
  service cloud. Un assistant le detecte au premier demarrage et vous
  guide. Le cloud fonctionne avec des credits ; 15 credits vous sont
  offerts a la creation du compte, de quoi produire vos premiers
  modeles sans rien payer.
  (CHIFFRE VERIFIE le 2026-08-28 dans la migration
  20260804150000_octroi_gratuit_15.sql : `credits ... 15`. La fiche
  disait 50 — un examinateur qui cree un compte aurait vu 15.)

CE QUE VOUS POUVEZ FAIRE

· Generer une image de reference a partir d'une description
· Convertir une image en maillage 3D texture
· Retoucher l'image avant la 3D : detourage, retouche par zone,
  agrandissement, vue arriere automatique
· Poser un squelette automatiquement et animer le resultat
· Retravailler le maillage : lissage, decimation, recentrage, UV
· Exporter en GLB, FBX, OBJ
· Suivre vos projets et revenir a n'importe quelle version anterieure

CONTENU GENERE PAR INTELLIGENCE ARTIFICIELLE

Les images et les modeles produits par cette application sont generes
par IA. Un bouton de signalement est present en permanence dans la barre
du haut, ainsi que sous chaque image generee : il permet de signaler un
contenu inapproprie, avec ou sans compte, et meme sans connexion. Un
filtre de contenu bloque les demandes a caractere sexuel, violent ou
illegal ; dans la version du Microsoft Store, ce filtre ne peut pas etre
desactive.

ACHATS

L'application ne vend rien en son sein. Les credits du service cloud
se gerent uniquement sur notre site. Aucun achat n'est necessaire pour
utiliser le mode local, qui reste gratuit et sans limite.

CONFIGURATION

Windows 10 ou 11 (64 bits). Pour le mode local : carte NVIDIA avec 8 Go
de memoire video au minimum, 12 Go recommandes, et environ 25 Go
d'espace disque pour les modeles. Sans carte NVIDIA, seul le mode cloud
est disponible.

Built with DINOv3 (Meta Platforms). Les licences des composants tiers
sont listees dans l'application, rubrique A propos.
